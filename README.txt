سند للحسابات — حزمة التثبيت على الآيفون (V220)

1) ارفع هذا المجلد كما هو على أي استضافة HTTPS مجانية:
   - Netlify Drop: افتح app.netlify.com/drop واسحب المجلد.
   - أو GitHub Pages: ارفع الملفات إلى مستودع وفعّل Pages.
   (لا يعمل التثبيت الكامل والعمل بلا إنترنت من ملف محلي؛ يلزم رابط https.)

2) على الآيفون افتح الرابط في Safari:
   زر المشاركة ⬆️ ← «إضافة إلى الشاشة الرئيسية» ← إضافة.

3) انقل بياناتك: بيانات Safari منفصلة عن التطبيق المثبّت.
   من النسخة القديمة: إدارة ← تصدير JSON، ثم داخل التطبيق المثبّت: استيراد JSON.

ملاحظة: كل البيانات محفوظة على جهازك فقط (IndexedDB). صدّر نسخة احتياطية دوريًا.
